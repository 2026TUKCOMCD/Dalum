## 📐 코드 컨벤션

### 브랜치 전략

```
main
└── develop
    ├── feat/{기능명}       # 새 기능 개발
    ├── refactor/{기능명}   # 리팩토링
    ├── fix/{기능명}        # 버그 수정
    ├── chore/{작업명}      # 설정·빌드 등 기타 작업
    └── setting/{작업명}    # 초기 설정
```

### 커밋 메시지

```
feat:     새로운 기능 추가
refactor: 코드 리팩토링
fix:      버그 수정
chore:    빌드·패키지·설정 변경
setting:  프로젝트 초기 설정
docs:     문서 수정
```
